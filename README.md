# Derived data

The original consolidated `filtered_data.csv` is approximately 33.6 MB, and the retained SAS dataset is approximately 47.7 MB. Both exceed GitHub's 25 MB browser-upload limit.

The portable CSV has therefore been split by year without changing its columns:

- `filtered_data_2017_2019.csv`
- `filtered_data_2020_2022.csv`

The original SAS binary dataset is intentionally omitted from the public upload package because it is larger than the browser-upload limit and is redundant with the portable derived CSV representation.
