# GitHub Upload Guide

## Repository name
`health-insurance-coverage-analytics`

## Description
SAS-based U.S. county health-insurance analytics project using 2017-2022 ACS data to examine coverage disparities across age, disability, education, work, income, poverty, and geography.

## Recommended topics
`sas`, `health-insurance`, `census-data`, `american-community-survey`, `data-analysis`, `public-policy`, `healthcare-analytics`, `descriptive-statistics`, `data-visualization`

## Upload steps
1. Create the repository as **Private**.
2. Upload the contents of this repository package to the repository root.
3. Confirm all raw and derived data files upload successfully; every included file is below the browser-upload threshold.
4. Confirm the README figure previews render.
5. Review `docs/REPRODUCIBILITY_NOTES.md`.
6. If the original SAS code is later found, add it before the final correction/publication pass.
7. Confirm coauthor permission for the report PDF.
8. Make the repository public only after the final portfolio-wide correction pass.

## Suggested resume line
**Health Insurance Coverage Analytics | SAS, U.S. Census ACS** - Analyzed county-level U.S. health-insurance coverage from 2017-2022 across age, disability, education, work, income, poverty, and geography using descriptive statistics, confidence intervals, trend visualization, and policy-oriented reporting.
